# Legacy Prompts — Gardenku

Folder ini menyimpan **prompt historis** agar dokumen lama tidak hilang ketika aturan Gardenku berkembang.

## File yang diarsipkan

- [`mp-v01.md`](mp-v01.md) — master prompt lama untuk pembuatan video kebun tropis.
- Lokasi sebelum dipindahkan: `prompt/mp-v01.md`.
- Isi arsip dipertahankan **tanpa perubahan**, termasuk format ide dan instruksi generasi lama.

## Hubungan dengan sistem saat ini

Arsip lama mengutamakan **video 10 detik**, biasanya satu `continuous take` dan kecenderungan `forward walkthrough`. Gardenku sekarang secara default memakai **beberapa shot independen sekitar 8 detik**, dengan kamera mengikuti hero subject, **kecuali pengguna meminta yang lain**.

Gunakan [`rules/analysis.md`](../../rules/analysis.md), [`rules/ideas.md`](../../rules/ideas.md), dan [`rules/prompts.md`](../../rules/prompts.md) sebagai aturan kerja utama saat ini. Arsip ini dapat dibaca sebagai referensi historis **bila pengguna memintanya**, bukan menggantikan aturan baru.
